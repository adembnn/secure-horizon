# Angles morts 01 : sécurité de l'extension Hold up elle-même

Date : 11 oct. 2026. Relecture en lecture seule (aucun code modifié). Périmètre : `extension/`, `extension_standalone/` (src/ et build `extension/`), `server/server.mjs`, `test_page/`, `standalone_test_page/`, `essai_reel/CE_QUI_PEUT_CASSER.md`.

Légende des preuves : **[PoC]** = reproduit dans un harnais Node qui charge le vrai `inject.js` (scripts hors repo : `scratchpad/poc.mjs` et `poc2.mjs`, à recopier dans `extension/tests/` lors du correctif) ; **[code]** = lu dans le code ; **[à tester]** = plausible, non reproduit.

Constats préalables : `inject.js` et `bridge.js` sont identiques octet pour octet dans `extension/` et `extension_standalone/extension/` (et `background.js` entre `src/` et build). Tout correctif se fait donc une fois dans `extension/`, puis `node extension_standalone/build_standalone.mjs`. `gitleaks` n'est pas installé ici : balayage manuel par motifs (clés AWS/GitHub/Slack/JWT/PEM, e-mails, 0x+64 hex) : aucun secret trouvé dans le périmètre. Aucun appel LLM dans l'extension ni le serveur (pas de surface d'injection de prompt).

## 2. Ce qui est sain (à citer)

- Messages : l'origine (`location.origin`) est lue dans le monde isolé, pas par la page ; `kind` (journal ou gate) est imposé par le pont ; la page ne peut pas forger un verdict (seul le SW répond) ; aucun `externally_connectable`, aucune ressource web accessible.
- Fermé par défaut : pont absent (2,5 s), contexte invalidé, erreur du moteur, onglet inconnu, UI indisponible, `params` illisibles = refus ou « non vérifié », jamais vert ; le mode autonome rejette `'ok'` (`standalone/background.js:51`).
- UI : tout contenu venant de la page (citation, adresse, méthode) passe par `textContent` ; shadow root fermé ; pas d'`innerHTML` avec des données.
- CSP : `script-src 'self'` ; autonome `connect-src 'none'`, sans fetch ni socket (`static_check.mjs` le vérifie et le packaging est refusé s'il échoue).
- Serveur : 127.0.0.1 seulement, contrôle du `Host` (anti DNS rebinding), CORS fermé aux pages web, corps borné (256 Ko), délais d'attente, aucune route de lecture de fichier.
- Pas de secret ni d'appel LLM ; pas de donnée personnelle réelle repérée ; `essai_reel` interdit explicitement phrase secrète, fonds réels et mainnet. Le moteur résiste aux types EIP-712 cycliques et à 20 000 niveaux d'imbrication (testé, moins de 300 ms).

## 3. Argument sécurité pour le pitch (3 lignes)

1. Nous attaquons notre propre barrière avant vous : getters, prototypes, iframes, inondation, port local usurpé ; chaque trou trouvé est listé avec correctif et test.
2. Mode autonome : zéro réseau (`connect-src 'none'`), zéro secret, zéro donnée personnelle, fermé par défaut, aucune surface d'injection de prompt (moteur déterministe, pas de LLM).
3. Honnêteté : ce que nous ne couvrons pas (WalletConnect, matériel, interface native du portefeuille) est écrit dans le README, avec la métrique de couverture.
