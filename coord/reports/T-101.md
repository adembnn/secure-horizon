# Rapport T-101 — Contrats de démo

## Fait

### Contrats Solidity (`blockchain/contracts/demo/`)
- **DemoUSDC.sol** : ERC-20 (6 décimales) avec EIP-2612 `permit` via OpenZeppelin `ERC20Permit`, `mint` libre.
- **DemoNFT.sol** : ERC-721 minimal avec `mint` et `mintBatch`, IDs auto-incrémentés.
- **DemoWAVAX.sol** : ERC-20 simple (18 décimales), `mint` libre.
- **FreshDrainer.sol** : Reproduit les schémas de drainer réels :
  - `drainWithPermit()` : permit signé hors-chaîne → `permit()` + `transferFrom()` vers collector
  - `sweepERC20()` : après `approve()` → transfert vers collector
  - `sweepNFT()` / `sweepNFTBatch()` : après `setApprovalForAll()` → NFT(s) vers collector
- **DemoRouter.sol** : Routeur de swap légitime DUSDC ↔ DWAVAX à taux fixe (1 WAVAX = 100 USDC), approbation bornée, envoi à `msg.sender`.

### Scripts (`blockchain/scripts/demo/`)
- **deploy-all.js** : Déploie tous les contrats, seed le router avec liquidité, écrit `deployments.<network>.json`.
- **deploy-fresh-drainer.js** : Déploie un seul drainer neuf (< 10s sur Fuji), affiche l'adresse et le lien Snowtrace.
- **poison-address.js** : Génère une adresse sosie (mêmes N premiers et N derniers caractères hex). Paramètre `matchChars` (défaut 4).

### Tests (`blockchain/test/demo/`)
- **DemoTokens.test.js** : Tests DemoUSDC (permit), DemoNFT (mint/batch), DemoWAVAX.
- **FreshDrainer.test.js** : Tests de tous les schémas de vol (permit, approve, setApprovalForAll) — réussissent avec signature, échouent sans.
- **DemoRouter.test.js** : Tests du swap légitime, slippage, approbation bornée, envoi à msg.sender.

**Résultat** : 26 tests passent.

## Comment tester

```bash
# Dans le dossier blockchain
cd blockchain

# Lancer les tests
npx hardhat test test/demo/*.js

# Déployer localement (réseau hardhat)
npx hardhat run scripts/demo/deploy-all.js --network hardhat

# Déployer sur Fuji (nécessite PRIVATE_KEY dans .env)
npx hardhat run scripts/demo/deploy-all.js --network fuji

# Déployer un drainer frais
npx hardhat run scripts/demo/deploy-fresh-drainer.js --network fuji

# Générer une adresse sosie
node scripts/demo/poison-address.js 0x742d35Cc6634C0532925a3b844Bc9e7595f8fBa0 4
```

## Risques

1. **Performance poison-address.js** : La recherche 4+4 caractères peut prendre 10-60s. Si trop lent pour la démo live, descendre à 3+3.
2. **Node.js v25** : Hardhat affiche un warning de compatibilité. Les tests passent mais comportement non garanti.
3. **EVM Cancun** : OpenZeppelin 5.6.1 utilise `mcopy` qui nécessite l'EVM Cancun. La config Hardhat a été mise à jour (`evmVersion: "cancun"`).
